# 모션 영상 제작

글자·도형·데이터를 코드로 움직이는 짧은 영상을 만든다. 이 스킬의 결과는 장면 구성표와 브라우저에서 재생되는 HTML 미리보기까지이고, MP4 출력은 승인 뒤의 별도 단계다.

## 언제 쓰나

- 키네틱 자막, 로고 등장, 막대·선 차트, 숫자 카운터, 진행 바, 앱·제품 소개 장면.
- 쓰지 않는 경우: 실사 촬영 편집, 캐릭터 연기·립싱크, AI 영상 생성. 다른 도구가 필요하다.

## 실행 환경

- 현재 폴더가 작업 폴더다. 요청 원문은 `REQUEST.md`에 있다.
- 사용자가 폴더를 지정했다면 `TARGET.md`에 경로와 권한(읽기 또는 수정)이 있다. 읽기 권한이면 그 폴더의 파일을 바꾸지 않는다.
- 결과 파일은 `output/` 아래에만 만든다. 수정 권한을 받은 대상 폴더만 예외다.
- 함께 쓰라고 지정된 설치 스킬이 `.claude/skills` 또는 `.agents/skills` 아래에 있으면 그 SKILL.md를 먼저 읽는다.
- 기본 동반 스킬: animation-vocabulary, improve-animations, review-animations, fixing-motion-performance.
- 패키지 설치처럼 네트워크가 필요한 단계는 실행하지 않고 필요 항목으로 적는다.
- 외부 게시·배포·발송·결제·삭제·대량 다운로드는 하지 않고 승인 필요로 남긴다.
- 마지막 응답은 한국어로 쓴다: 한 줄 결론, 만든·바꾼 파일 목록, 실제로 확인한 것과 확인하지 못한 것, 사용자 승인 필요 항목.

## 먼저 확인할 것

1. `REQUEST.md`에서 목적(자막·로고·차트·앱 소개 등), 길이, 화면 비율, 꼭 넣을 문구, 브랜드 색, 데이터를 찾는다.
2. 화면 크기는 1920x1080(가로) 또는 1080x1920(세로)이다. 정하지 않았으면 릴스·쇼츠·세로라는 말이 있을 때 1080x1920, 아니면 1920x1080.
3. 길이: 정하지 않았으면 전체 15초, 장면 하나는 2~6초.
4. 색: 정하지 않았으면 배경 #111111, 글자 #FFFFFF, 강조 #FF6B00 한 가지.
5. 데이터·로고: 사용자가 준 숫자와 파일만 쓴다. 숫자가 없으면 화면에 '예시 데이터' 표시를 넣고, 로고 파일이 없으면 브랜드 이름 글자로 대신한다.
6. 렌더 도구: 이 스킬은 명령을 실행하지 않으므로 설치 여부를 '미확인'으로 적는다.

## 절차

1. **요구 정리**
   - 위 항목을 표로 정리하고, 기본값을 쓴 칸에는 '가정'이라고 표시한다.
   - 산출물: `output/storyboard.md`의 '요구와 가정'
2. **대본과 장면 구성표**
   - 장면마다 번호, 시작~끝 초, 화면 문구, 움직임, 색, 전환을 정한다.
   - 화면 문구는 장면 길이(초)×6자 이내(공백 제외), 한 줄은 가로 화면 24자·세로 화면 14자 이내다.
   - 등장 0.3~0.8초, 퇴장 0.2~0.5초, 장면 전환 0.3~0.6초로 맞춘다.
   - 산출물: `output/storyboard.md`
3. **장면 코드**
   - `output/motion.html` 한 파일로 만든다. 외부 네트워크·외부 라이브러리·웹 글꼴 없이 인라인 CSS keyframes와 JS requestAnimationFrame만 쓴다.
   - 선택한 해상도의 고정 무대를 창 크기에 맞춰 비율 그대로 축소한다. 가장자리 5%는 글자를 두지 않는 안전 영역이다.
   - 시간은 하나의 타임라인(밀리초)으로 계산해, 정지·이동 뒤에도 같은 시점이면 같은 화면이 나오게 한다.
   - 조작: 재생/정지, 이전·다음 장면, 처음으로 버튼과 현재 시간·장면 번호 표시. Space는 재생/정지, ←·→는 장면 이동.
   - `prefers-reduced-motion: reduce`이면 이동·확대·회전 대신 0.2초 이하 페이드나 정지 화면을 쓴다.
   - 글꼴은 시스템 글꼴 스택: `system-ui, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`.
   - 1초에 3번 넘게 번쩍이는 효과는 쓰지 않는다.
   - 산출물: `output/motion.html`
4. **자체 점검**
   - 파일을 다시 읽어 확인한다: `src`·`href`·`url(` 값이 `http`나 `//`로 시작하는 곳 0개, `<script src` 0개.
   - 장면 수·길이·문구가 storyboard와 같은지, reduced-motion 처리가 있는지 본다.
   - 산출물: `output/README.md`의 '점검 결과'
5. **미리보기 안내와 승인 요청**
   - 브라우저로 여는 방법, 총 길이, 장면 목록, 승인받을 항목(문구·색·속도·길이)을 쓴다.
   - 산출물: `output/README.md`
6. **출력 조건 정리**
   - MP4는 승인 뒤, 렌더 도구가 설치된 환경에서만 만든다.
   - 후보는 HyperFrames(Node.js 22 이상과 FFmpeg 필요)나 Remotion이다. 필요한 도구·설치 항목·비용 조건만 적는다.
   - 산출물: `output/README.md`의 'MP4 출력 조건과 비용'

## 결과물 형식

- `output/storyboard.md` — 목차: 1. 요구와 가정 / 2. 장면 구성표 / 3. 대본(자막·나레이션 전문) / 4. 색과 글꼴
  - 장면 구성표 머리글: `| 장면 | 시작~끝(초) | 화면 문구 | 움직임 | 색 | 전환 |`
- `output/motion.html` — 단일 파일. 맨 위 주석에 해상도·총 길이·장면 수를 적는다.
- `output/README.md` — 목차: 1. 미리보기 방법 / 2. 길이와 장면 목록 / 3. 점검 결과 / 4. 승인 요청 항목 / 5. MP4 출력 조건과 비용 / 6. 확인하지 못한 것
  - 장면 목록 머리글: `| 장면 | 시간 | 내용 |`
  - 점검 결과 머리글: `| 항목 | 결과 | 근거 |`

## 승인·안전 기준

- 사용자 승인 전에는 MP4 렌더·업로드·게시를 하지 않는다. 승인 뒤에도 도구 설치, 클라우드 렌더, 유료 음원·글꼴 구매는 따로 승인받는다.
- HyperFrames는 오픈소스지만 AI 호출 사용량, 클라우드 렌더, 유료 소재 비용까지 자동으로 무료가 되지는 않는다. README에 이 조건을 적는다.
- 미리보기는 시스템 글꼴을 쓰므로 렌더 환경에서 글꼴이 바뀔 수 있다. 사용권이 확인된 글꼴 파일 지정을 승인 항목에 넣는다.
- 사용자가 준 로고·데이터만 쓴다. 다른 회사의 로고·상표, 권리를 확인하지 않은 음악·영상은 넣지 않는다.

## 하지 않는 것

- 캐릭터 동작, 립싱크, 실사 합성. 참고 가이드의 '100개'도 자막·로고·차트 등 12종을 문구·색만 바꾼 변형이며 캐릭터 동작 100종이 아니다.
- 패키지 설치, CDN·웹 글꼴 연결.
- MP4 파일이 실제로 생기지 않았는데 영상을 만들었다고 보고하기. 실제로 만든 파일만 경로와 함께 적는다.
- `output/` 밖이나 읽기 권한 폴더에 파일 쓰기.
