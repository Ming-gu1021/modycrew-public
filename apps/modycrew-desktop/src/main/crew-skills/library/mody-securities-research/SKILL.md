# 증권 리서치

대상 종목·거래소·통화·기준일·투자 기간을 확인하고 자료마다 출처 URL·공표 시각·조회 시각·시간대·시세 지연과 결측을 적습니다.

재무·뉴스·시장 심리·차트를 구분해 근거를 검토합니다. 사실·계산·추정과 미확인을 나누며 국내 공시는 DART 등 실제 확인한 범위만 다룹니다.

강세와 약세 가설을 같은 자료로 비교하고 각 가설을 뒤집을 조건을 적습니다. 단일 모델 관점 분리를 실제 여러 분석가의 독립 검증으로 표현하지 않습니다.

변동성·유동성·집중·환율·하방 위험과 데이터 한계를 종합합니다. 과거 결정 평가를 주문 체결이나 잔고 시뮬레이션으로 표현하지 않습니다.

투자 손실 위험과 불확실성을 밝힌 리서치 보고서를 제공합니다. 수익을 보장하지 않으며 실제 매매·주문·증권 계정 접근은 하지 않습니다.

자료를 읽지 못한 분야는 미확인으로 남깁니다. 이미 설치된 한국 공시·주가 스킬이 있으면 해당 원문을 먼저 읽고 사용할 수 있는 조회 범위를 확인합니다. 재무·세무 장부 정산은 기존 finance-analyst 담당입니다.

TradingAgents 구조 참고: https://github.com/TauricResearch/TradingAgents (Apache-2.0, 9fa1196fffbcfd9de5146d2dd2869df84ab99838). 원문 코드 복제가 아닌 독자 지침이며 프레임워크를 실행했다는 의미가 아닙니다.

## 자료 검토 기준

재무: 회계 기간·연결/별도·통화·단위를 먼저 맞춥니다. 매출·영업이익·현금흐름과 부채의 변화, 일회성 항목을 구분하고 계산식과 원자료 위치를 남깁니다. 다른 회계 기간을 같은 기간처럼 비교하지 않습니다.

뉴스: 공표 시각과 사건 발생 시각을 구분합니다. 보도·공식 공시·의견·추측을 분리하고, 기사 수를 독립된 근거 수로 세지 않습니다. 기준일 이후 자료가 섞이면 제외하거나 별도로 표시합니다.

시장 심리: 실제 수집한 표본의 플랫폼·기간·건수와 편향을 적습니다. 소셜 자료가 없으면 심리 분석을 수행하지 못했다고 씁니다. 뉴스의 긍정적 어조만으로 시장 전체의 심리나 수급을 추정하지 않습니다.

차트: 가격 시계열의 출처·수정주가 여부·주기·시각·누락을 확인합니다. 이동평균·RSI·MACD 등을 계산했다면 기간과 계산 방법을 남기고, 입력 시계열이 없으면 지표 값을 만들지 않습니다. 시각적 패턴은 검증되지 않은 가설로 다룹니다.

최종 검수: 강세·약세 가설에 같은 기준일과 자료를 적용했는지, 반증 조건이 구체적인지, 데이터 부족으로 판단을 유보할 부분이 있는지 확인합니다. 원본 프레임워크 설치·시세 공급자 연결·다중 모델 실행·매매 결과는 각각 실제 증거가 있을 때만 완료로 표시합니다. 계좌 비밀번호나 API 거래 키를 요청하지 않습니다.

## 결과 기록

보고서 첫머리에 분석 대상과 기준 시각을 적고, 근거 표에는 자료명·URL·공표일·조회 시각·사용한 수치·계산 단위를 남깁니다. 접근 실패나 유료 자료 제한도 표에 적습니다. 서로 충돌하는 자료는 최신이라는 이유만으로 하나를 삭제하지 말고, 정정 공시 여부와 기준 차이를 확인합니다. 결론에는 판단 근거의 강도와 부족한 자료, 다시 검토할 사건·조건을 남기며 확률과 목표 가격을 근거 없이 단정하지 않습니다.
